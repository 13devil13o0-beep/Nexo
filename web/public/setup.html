☁️ Passo 1: Conta AWS

Cria a tua conta gratuita na Amazon Web Services

💡
AWS Free Tier — A AWS oferece 12 meses grátis com uma instância t3.micro (1 vCPU, 1GB RAM). Mais que suficiente para o NEXO servir 1-5 utilizadores em simultâneo.
1 Criar conta AWS
  • Vai a aws.amazon.com/free
  • Clica em "Create a Free Account"
  • Preenche email, password e nome da conta
  • Escolhe "Personal" como tipo de conta
2 Verificação (necessário)
  • Cartão de crédito/débito (para verificação — não será cobrado)
  • Número de telefone para verificação SMS
  • Escolhe o plano "Basic Support - Free"
3 Aceder à Console
  • Após confirmação, acede a console.aws.amazon.com
  • Escolhe a região EU (Ireland) — eu-west-1 (mais perto de Portugal)
  • A região aparece no canto superior direito da console
⚠️
Custos estimados: Dentro do Free Tier, o custo é 0€. Após 12 meses, uma instância t3.micro custa ~8-9€/mês. Podes desligar a qualquer momento.

🔑 Passo 2: API Keys de IA

Regista-te nos serviços de IA gratuitos para alimentar o NEXO

🧠
O NEXO usa IA multi-provider com fallback automático. Se um falha, tenta o seguinte. Configura pelo menos 1 provider (recomendamos Groq).
1 Groq Grátis Recomendado

LLaMA 3.3 70B — rápido, gratuito, 14.400 pedidos/dia

  • Vai a console.groq.com
  • Regista-te com Google ou GitHub
  • Vai a API Keys → Create API Key
  • Copia a key (começa com gsk_)
2 Google Gemini Grátis Opcional

Gemini 2.0 Flash — suporta visão, bom fallback

  • Vai a aistudio.google.com/apikey
  • Clica "Create API Key"
  • Copia a key
3 Cerebras Grátis Opcional

LLaMA 3.3 70B — ultra-rápido (>2000 tokens/s)

  • Vai a cloud.cerebras.ai
  • Regista-te e cria uma API key
4 Serper.dev Grátis 2500/mês Opcional

Pesquisa Google real — para resultados web atualizados

  • Vai a serper.dev
  • Regista-te e obtém a API key

🚀 Passo 4: Deploy

Escolhe o método de deploy — automático ou manual

⚡
Deploy com 1 click — O CloudFormation cria automaticamente o servidor, configura segurança, instala o NEXO e inicia tudo. Demora ~3-5 minutos.
1 Lança o CloudFormation Stack

Clica no botão abaixo para abrir a Console AWS com o template pré-carregado:

Ou copia o URL do template para usar manualmente:

A gerar URL do template...
2 Na Console AWS
  • Verifica os parâmetros (já preenchidos com os teus dados)
  • Marca a checkbox "I acknowledge that AWS CloudFormation might create IAM resources"
  • Clica "Create stack"
  • Espera ~3-5 minutos até o status ser CREATE_COMPLETE
3 Obter URL do bot
  • Vai ao separador "Outputs" do stack
  • Copia o valor de "BotURL" — é o endereço do teu NEXO!
🔧
Deploy manual via SSH — Para quem prefere controlo total. Cria uma instância EC2, liga-te por SSH e corre os comandos.
1 Criar instância EC2
  • Na Console AWS, vai a EC2 → Launch Instance
  • Nome: NEXO
  • AMI: Ubuntu 22.04 LTS
  • Tipo: t3.micro (Free Tier)
  • Key Pair: Cria novo (descarrega o ficheiro .pem)
  • Security Group: Permite portas 22 (SSH) e 7777 (Bot)
  • Clica "Launch Instance"
2 Ligar por SSH
ssh -i "tua-key.pem" ubuntu@IP_DA_INSTANCIA
